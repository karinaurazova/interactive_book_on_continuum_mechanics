## Экран M04.1 — Малый тетраэдр

### Концепт

Рассмотрим очень малый тетраэдральный элемент в окрестности выбранной точки.

Три его грани совпадают с координатными площадками, а четвёртая имеет произвольную единичную нормаль

[
mathbf n.
]

### Основной текст

На наклонной грани действует traction

[
mathbf t(mathbf n),
]

а на координатных гранях — traction-векторы, связанные с направлениями

[
mathbf e_1,mathbf e_2,mathbf e_3.
]

Если записать баланс линейного импульса для всё меньшего тетраэдра, можно установить связь между этими векторами.

### Интерактив

**Cauchy Tetrahedron**

Пользователь может:

- вращать (mathbf n);
- менять размер (h);
- включать поверхностные силы;
- включать объёмную силу;
- отображать площади граней.

## Экран M04.2 — Почему важны порядки (h^2) и (h^3)?

### Основной текст

Пусть характерный линейный размер тетраэдра равен (h).

Площади его граней имеют порядок

[
Asim h^2,
]

поэтому результирующие поверхностные силы имеют порядок

[
F_{mathrm{surface}}sim h^2.
]

Объём тетраэдра имеет порядок

[
Vsim h^3,
]

следовательно, объёмные силы и инерционный член при регулярных полях имеют порядок

[
F_{mathrm{volume}}sim h^3.
]

После деления уравнения баланса на (h^2) и перехода к пределу (h	o0) объёмные и инерционные члены становятся пренебрежимо малы относительно поверхностных.

### Важная оговорка

Это не означает, что объёмные силы вообще не важны в механике.

Они исчезают именно в этом локальном предельном выводе зависимости traction от ориентации площадки.

### Интерактив

При уменьшении (h):

- поверхностные стрелки уменьшаются как (h^2);
- объёмный вклад — как (h^3);
- рядом динамически показывается отношение (h^3/h^2=h).

### Do not confuse

> «Объёмный член исчезает в выводе» ≠ «объёмные силы не существуют».

## Экран M04.3 — Геометрия площадей

Для наклонной грани площади проекций на координатные плоскости связаны с компонентами нормали.

Если (A) — площадь наклонной грани, то соответствующие ориентированные проекции имеют величины, пропорциональные

[
n_1A,qquad
n_2A,qquad
n_3A.
]

Именно поэтому компоненты (mathbf n) входят в итоговую формулу как коэффициенты при traction-векторах координатных площадок.

### Интерактив

Пользователь вращает наклонную грань.

На трёх координатных плоскостях меняются её проекции.

Рядом обновляются:

[
n_1, n_2, n_3.
]

## Экран M04.4 — Формула Коши

### Основной текст

После записи баланса и перехода к пределу получаем линейную зависимость traction от нормали.

При фиксированной точке:

[
mathbf t(mathbf n)
=
n_1mathbf t^{(1)}
+
n_2mathbf t^{(2)}
+
n_3mathbf t^{(3)}.
]

Эту связь удобно записать с помощью линейного оператора второго порядка — тензора напряжений Коши:

[
oxed{
mathbf t(mathbf n)
=
oldsymbol{sigma}mathbf n
}
]

Это и есть **формула Коши**.

### Смысл

Тензор (oldsymbol{sigma}) кодирует всё семейство traction-векторов в данной точке.

Чтобы узнать действие на площадке с нормалью (mathbf n), достаточно применить к (mathbf n) линейный оператор (oldsymbol{sigma}).

## Экран M04.5 — Матричная и индексная запись

В выбранном декартовом базисе:

[
oldsymbol{sigma}
=
egin{bmatrix}
sigma_{11}&sigma_{12}&sigma_{13}\
sigma_{21}&sigma_{22}&sigma_{23}\
sigma_{31}&sigma_{32}&sigma_{33}
end{bmatrix}.
]

Тогда

[
mathbf t
=
oldsymbol{sigma}mathbf n.
]

В индексной форме при принятой в этом проекте конвенции:

[
oxed{
t_i=sigma_{ij}n_j
}
]

с суммированием по повторяющемуся индексу (j).

### Notation Inspector

**Direct**

[
mathbf t=oldsymbol{sigma}mathbf n
]

**Index**

[
t_i=sigma_{ij}n_j
]

**Matrix**

[
egin{bmatrix}
t_1\t_2\t_3
end{bmatrix}
=
egin{bmatrix}
sigma_{11}&sigma_{12}&sigma_{13}\
sigma_{21}&sigma_{22}&sigma_{23}\
sigma_{31}&sigma_{32}&sigma_{33}
end{bmatrix}
egin{bmatrix}
n_1\n_2\n_3
end{bmatrix}
]

**Python**

```python
t = sigma @ n
```

## Экран M04.6 — Тензор и его компоненты — не одно и то же

### Основной текст

(oldsymbol{sigma}) — геометрический объект, не зависящий от того, каким базисом мы пользуемся для его описания.

Матрица ([sigma_{ij}]) — набор компонент этого объекта в выбранном базисе.

При смене базиса компоненты изменяются, но сам физический тензор остаётся тем же.

Эта мысль станет центральной в модуле о преобразовании координат.

### Do not confuse

> Тензор — не просто «матрица 3×3».  
> Матрица является координатным представлением тензора в конкретном базисе.

## Экран M04.7 — Как читать (sigma_{ij})?

В этом проекте используется конвенция, согласованная с

[
t_i=sigma_{ij}n_j.
]

Для координатной площадки с нормалью (mathbf e_j):

[
mathbf t^{(j)}
=
oldsymbol{sigma}mathbf e_j.
]

Следовательно, (j)-й столбец матрицы ([sigma_{ij}]) содержит компоненты traction-вектора на площадке с нормалью (mathbf e_j).

### Интерактив

Наведение на (sigma_{23}):

- подсвечивает площадку с нормалью (mathbf e_3);
- подсвечивает компоненту traction вдоль (mathbf e_2);
- показывает соответствующую стрелку на 3D-элементе.

### Notation warning

В литературе встречаются разные соглашения о расположении индексов и о том, записываются ли traction-векторы по столбцам или строкам.

Поэтому в учебнике всегда сначала фиксируется формула Коши, а затем из неё выводится смысл индексов.
